# Launch kit

## English post

I built RelayCrew, a small Agent Skill for Codex and Claude Code.

The idea: use a small team when tasks are independent, give each worker a focused handoff, and keep conflicting edits in sequence. The optional offline planner checks dependencies, file claims, and shared resources. It has zero npm dependencies and needs no API key.

There is a runnable example, tests, and a solo fallback when native delegation is unavailable. This is an early release; I would particularly value examples where coordination helped, or where staying solo was better.

Try it: https://github.com/ScriptNegative/relaycrew

## Discovery plan

1. Publish the repository with a clear description, relevant topics, a runnable example, and a tagged release. Keep performance claims limited to measured evidence.
2. Share one concrete demonstration from your own public account in a community that permits project showcases. Check its rules first. Use the post above and explain the problem instead of asking for reciprocal stars.
3. After collecting real feedback, consider a focused submission to an Agent Skills directory that accepts new projects. Follow that directory's current contribution requirements; avoid mass submissions.
4. Ask early users for a minimal task split and observed outcome. Prioritize one repeatable pain point per improvement. Publish any benchmark with the baseline, model, host, acceptance criteria, and actual usage data.

These posts are prepared drafts. No social post, direct message, directory submission, paid promotion, or outreach has been sent as part of creating this kit. Stars and adoption are not guaranteed.
